# Two-minute audience discovery

Open /#present. Six stage budgets total 120 seconds. Verify local judging and submission-format limits separately.

1. 0–15: explain higher pitch = higher anomaly and invite a prediction.
2. 15–40: play both periods, accept the judge’s response or uncertainty.
3. 40–65: reveal actual dates, means and computed difference. Explain the baseline.
4. 65–90: scrub verified NASA endpoints, play one month and describe the pairing. Briefly show the cooler-year discovery. These are three selected snapshots, not a continuous NASA movie.
5. 90–110: report actual pilot observations and a concrete change. If testing has not happened, explicitly say so.
6. 110–120: show the classroom lesson and printable teacher guide. Invite an educator pilot.

Test speakers beforehand and keep the local server available at the venue. No human results are seeded. Draft Arabic guidance needs educator review. Complete docs/pilot-report.md only with actual feedback.
