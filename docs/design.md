# ECHO EARTH visual design

The November 13, 2026 rehearsal redesign takes its direction from NASA public science publishing: bold Public Sans headings, black and white page structure, NASA-blue actions, authentic Earth imagery, and clearly readable scientific values. Eyebrow headings and decorative status badges were removed. No NASA insignia is used as project branding.

The introduction uses an authentic credited Blue Marble composite. Dark listening panels use a shared canvas component reading the actual post-volume audio signal. Before the blind reveal, only measured amplitude changes the rings; frequency waveforms appear after reveal and in the explorer and laboratory. The visual loop runs only for its active audio sequence, respects reduced motion, and cleans up observers, subscriptions and animation frames on unmount. Native canvas adds no animation or 3D runtime dependency.

The user's requested design-skill collection was installed into the local Codex skills directory from https://github.com/freshtechbro/claudedesignskills at commit `1da73febff0c3e1dfefc07f8a5ef8f7d1dfdb6cd`: all 22 design skills, without duplicating the existing system skill-creator utility. Modern Web Design and the existing unslop-ui skill guided this implementation. Installing the collection does not bundle its example libraries into the application.

Public Sans and IBM Plex Mono are served locally. Existing NASA observations, fixed pitch mapping, consent flow, frame bindings and download artifacts retain their scientific meaning.
